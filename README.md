# 🤖 AURA - AI Personal Assistant

AURA is an AI-powered personal assistant built using Python.

## Features

- AI-powered intent detection
- Task management
- Priority-based tasks
- Notes management
- Reminder management
- Mathematical calculator
- Search
- Conversation history
- Productivity dashboard
- SQLite database
- Machine learning

## AI Technology

AURA uses:

- TF-IDF Vectorization
- Logistic Regression
- Natural Language Processing
- Intent Classification

## Technologies

- Python
- Streamlit
- Scikit-learn
- SQLite
- Pandas
- NumPy
